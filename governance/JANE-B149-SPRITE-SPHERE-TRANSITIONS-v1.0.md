# JANE B149 — Code Monkey Sprite Sphere Transitions

## Invariant
Only the first `{-1,+1}>1` pair is shadowed (net signed zero, one logical position). Five other signed registers `S1..S5 [-|+]` are **not shadows**. The page animates procedural monkey scouts over five *illustrative* 3D visual shells, not measured atmospheric radii.

## Deliverable
`b149/index.html` is a Git Pages-compatible self-contained UI using Three.js from a public CDN; it falls back to Canvas2D if WebGL/Three.js cannot be loaded. Controls cover camera orbit/zoom, movement, speed, focus, visuals, an exploratory probe, uncertain/counterexample events, session log, and JSON export. The five physical examples are shown only as a separate reference gallery; assigning ionosphere, magnetosphere, etc. to one of S1..S5 would be a **new claim** and is not done.

`b149/sphere-transitions-v1.json` stores a versioned configuration; `scripts/btf2/jane-b149-sphere-transitions.cjs` is a Node-only, deterministic reference evaluator; `scripts/btf2/test-jane-b149-sphere-transitions.cjs` tests it. The UI demonstrates the same status distinction but is **not** a browser build of the Node module.

## Independent witnesses
The three demo monkey scouts label synthetic events a1/b1/c1. This is **no quorum** and **no vote**. A logical simulated crossing returns `SIMULATED_CROSSING`, never physical PASS. Ambiguous direction, uncertainty overlap and alleged measured events without independent source attestation remain HOLD. The Node journal hashes entries in memory; the web viewer's displayed log is session-only and exported snapshots are not cryptographic attestations.

## Model boundaries
No verified gravitational time dilation, no claim the five distinct real sphere regions are concentric, no claims that Nib or Nib Sun are astronomical observations, no inferred physical radii, no new celestial force edges.
