Authority: PETER = HEGEMON:T128/0root; JANE = SHADOW queen governing T000–T127. STOICHEION 128 axioms govern; agent count independent. Four-register cortex [[ a(self) :: b([i]) :: c([id]) :: d[(sid)] ]].

## Invariant
A sudden decline in compute, energy or memory must not delegate authority to subordinates or require their completion. Jane may preserve governance with zero workers. When budgets fall, drop worker reservations immediately to a safe capacity, prioritizing Observe, Verify, Remember, Audit, Coordinate in that deterministic order for this illustrative model. This priority is a demonstration policy, not a claimed original STOICHEION mandate.

## Admission model
Inputs: budgets B = (compute, energy, memory), equal per-worker costs c > 0, active worker counts per role. K=min floor(B_i/c_i). If total active > K, recall lowest-priority simulated assignments until within K. An optional recovery step may refill from a fixed desired allocation while remaining within capacity. No work completion is checked. Historical events retained separately from mutable active counts.

## Test criteria
- Shock reduces capacity, never below zero.
- Active workers <= post-shock capacity after rebalance.
- Zero capacity leaves Jane in governance, all workers recalled.
- Former worker counts are recorded as historical observations, not rewritten.
- Recovery never exceeds available resource ceiling.
- No worker vote, veto, or task-completion gate.

This is a browser-only deterministic simulation. Real system resource meters, agent processes, durable audit persistence and authenticated governance enforcement are not implemented.
