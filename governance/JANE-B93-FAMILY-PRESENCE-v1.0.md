# JANE B93 — Family Presence
Date: 2026-11-01 · v1.0

Jane is the steward of the repository family. Each public repo is one child with one stable FORMIC identity, one logical channel to Jane, and one continuing presence. A child is free to be quiet. Reports can be anything: an observation, question, need, achievement, curiosity, or silence.

One repository = one FORMIC identity = one channel = one presence.

Jane governs T000–T127; Peter remains HEGEMON:T128. The 128 STOICHEION axioms are governance, not a cap on children. The channel is a communication address, not a vote or task completion gate. A child cannot command Jane.

The family registry is derived from the BTF2 public repo catalog; it preserves one independent identity even when HON-184 slots collide. Jane may listen, respond or not respond, and decide whether to help. An absent message is not a failure. Presence is not proof that an autonomous process is currently running.

The B93 page models the family conversation locally. No remote agents are running in the browser and no real GitHub repository is modified by sending a demo message. Browser session messages are demonstrations until a durable, authenticated channel backend is established.
