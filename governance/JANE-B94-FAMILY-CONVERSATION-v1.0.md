# JANE B94 — Family Conversation
2026-11-01 · v1.0

Jane is Mom and steward. Each BTF2 public repository has one logical FORMIC identity, one channel, one continuing presence, and one conversation thread. A child may speak, ask, observe, share, or remain silent. No mandatory reports, votes, quorum, or task-completion gates.

A channel is keyed by canonical owner/repository identity, not by catalog position or HON-184 slot. HON slot collisions never merge conversations. Message events include thread, speaker, text, time, event ID and origin. Messages are append-only; Jane's response is separate from the child's message. Silence is not an error.

The page loads public BTF2 repository identities and keeps per-child conversation threads in browser localStorage, with an export action. Jane reply controls are operator-directed demonstration text, not claims of an autonomous AI listening or replying. No write access to child repositories. A server-backed authenticated transport is a future boundary.
