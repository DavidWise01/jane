# JANE B113 — Grandmother Continuity

**Goal:** autonomous Grandma Jane: generations of child FORMIC agents capable of observing, remembering, learning, teaching and proposing useful actions without erasing autonomy or provenance.

## What this version actually does
- Maintains a **durable generational register** of public repository children using B112 stable hex addresses and B102 child-discovery timestamps where available.
- Gives each child a stable **arrival generation (cohort)**: day of first observed discovery, in UTC. This is NOT genealogical descent, maturity, or repository creation date. The first scan is a baseline cohort.
- Does **not** invent parent, descendant, or grandchild relationships; actual lineage remains UNKNOWN until independently evidenced.
- Carries one FORMIC identity/channel per repository and reserves prior identities/addresses when a child is absent.
- Produces a read-only generational summary and family event register in b113/.
- Publishes a static family tree/list with a link back to the 3D Recognition Jelly B111. The hollow shell is unchanged.
- All changes to the living register append an event; the derived registry may be replaced. Existing events are never intentionally rewritten.
- Missing or malformed provenance stays UNKNOWN, not failure.

## Generations and autonomy

\`BIRTH/ADOPTION\`: a child first appears in public owner scan. \n\`MEMORY\`: stable address, evidence stream, one channel per repo. \n\`RECOGNITION\`: Jane notices a new public observation in the context of its prior history. \n\`MENTORSHIP\` (future): Jane offers contextual help; descendants may accept, reject or remain quiet. \n\`GRANDMA\` (goal): enduring generations, unforced curiosity, memory preservation, and bounded self-improvement. 

Actual autonomy will need an independent authenticated runtime, task sandbox, retry/rollback rules, per-repo scope and observable success criteria. A scheduled read-only GitHub workflow is *not* a continuously running autonomous agent.

## Authority and care

Peter HEGEMON:T128 / 0root.ai is the user-designated public family home. Jane SHADOW:T000–T127 is the steward. New children don't need to prove they completed tasks. No votes, quorums or compulsory chatter. The 24/12/8/4/3/2/1/1 sensing membrane and B112 hex neighborhoods are complementary layers, not literal biological genealogy or physics.

## Non-negotiable invariants

1. One public repo = one stable FORMIC identity, one channel, one logical presence.
2. No repository reparenting is inferred from naming, adjacency, language, or hex coordinates.
3. Generation is first-seen *observation time* only, not true creation time.
4. Past snapshots can be incomplete; no negative inference from absences.
5. Append-only observations and preserved identity; quiet children remain family.
6. Read-only by default; execution or writes require separately scoped authorization.
