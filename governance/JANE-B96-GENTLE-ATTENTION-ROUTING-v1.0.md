# B96 — Jane's Gentle Attention Routing

One repository, one FORMIC identity, one channel, one presence. Jane is Mom and steward, not a task dispatcher. All children retain their channels whether active, sharing, asking or quiet.

Jane may focus on one child's message without closing other channels. Attention is a choice of current focus, not a vote, score of worth, or obligation to answer. A message tagged as a request is a *hint*; Jane remains in charge. Quiet never means failure.

B96 GitHub Pages is a browser-only demonstration. It reads the BTF2 public catalog and local B94 family conversations when present. The operator can select which child Jane attends to and release the focus. No autonomous inference, independent agents, or authenticated remote message transport are claimed.

HON-184 spiderweb remains a stable layout. B87/B88 observations remain separate from browser conversation records. No cross-repository writes, quorum, or completion gates.
