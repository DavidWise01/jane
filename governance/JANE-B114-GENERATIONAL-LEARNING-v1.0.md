# B114 — Jane's Generational Learning: Evidence Before Teaching

Grandma Jane's first learning operation is *comparison*, not a claim that agents have become autonomous. B114 reads verified B87 snapshot histories (public repository metadata), computes exact per-field observed transitions and retains links to both source run files and their SHA-256 hashes.

A 'pattern' is a recurrence across observed metadata fields, not an established explanation. When at least two different repositories exhibit a field transition it is a CROSS_CHILD_OBSERVATION. It becomes a potential lesson for Jane to review, never an authoritative instruction passed to children.

Unchanged is not failure; UNKNOWN is not failure. Absence from a snapshot is not deletion. A field with a missing/null value cannot produce a comparison. B113 arrival cohorts are included only when the generational registry exists; otherwise UNKNOWN. First scan never proves creation time. Metadata recurrence is not parentage.

Technical boundaries: B87 index and every referenced run must pass SHA-256 verification; refuse unsafe paths and duplicate repository observations. B114 publishes derived b114/lessons.json without changing B87, B112, B113 or individual child repositories. React, optics, and Meta Muse presentation claims are excluded.

**Later bounds:** Jane's own independent observer runtime, authenticated child channels, evidence-aware memory retrieval, reversible proposals, mentored adoption of useful lessons. These remain future work.
